# TACT-AIM 系 MOD の SVG コスチュームの流儀

対象: `TACT-AIM-MYTHOLOGY`（本命）と `TACT-AIM-MOD` の全コスチューム。
見た目の判断は作者のもの。作者の作風指示には即従い、却下された方向は繰り返さない。
コンテンツ追加の総合手順は `tact-aim-add-content`。

## 登録は2箇所必須

- `src/distilled/Pen_All/assets.ts` のコスチューム表 と `tools/mythology-costumes.json`
  （detranspile フックが sb3 へ注入）。
- 片方だけだと TS では出るが sb3 に入らない（逆も同じ）。
- 生成は `tools/make_new_costumes.py`（キャラ・武器）と
  `tools/make_mythic_skins.py`（神話 ++）に処理を足すのが既存の作り。
  ジェネレータの挿入は複数パス化されているので、新規コスチュームを
  同回の別コスチュームのアンカーにできる。

## 顔の向き（最重要）

- コスチュームは **+x（右）向き**で描かれ、頭頂は **−x 側**。
- 正面ポートレートは画像を **90° CW 回転**した姿。
- 装飾を置く前に、原画を回転させて顔の解剖（目・頭頂・顎の位置）を確定する。
  作者が「顔がどこか理解してない」と指摘した実績のある最重要ポイント。
- 神話スキンの描き下ろしは、原画を回して顔向きを確定してから描き、
  作者の確認を取ってから次へ進む（1体ずつが作者の方針）。

## 色

- 原作パレットから実測した色だけを使う:
  赤 #ff0000、金 #e8aa00、オレンジ #ff6e00、水色 #00f2ff、緑 #2aff00、
  ピンク #ff00dc、紫 #7664ff、紺 #00064d、灰 #9a9a9a、濃灰 #333333、黒、白。
- 演出・カットインの色調も本家に寄せる（帯は本家の黒、縁色は上記の実測色のみ）。
- **作者の作風指示への従い方**: 「色を変えるな」と言われたら、塗り自体の加工
  （グラデーション化など）に切り替え、上に物を描き足さない。
  リカラー＋飾りの足し算は「色変えてるだけ」「余計」と却下された実績がある。
  金属感は「元の塗りを金属グラデーションに差し替える」のが確定した形
  （例: 単色 → 淡色→シャイン帯→基色→濃色の斜めグラデーション。輪郭・目は不変）。
- 神話スキンは金色統一ではなく **23体を1体ずつ個別コンセプト**で描き下ろすのが
  作者の方針（統一リカラーは却下済み）。

## 形

- コスチュームはタイトにトリミングされている（余白なし）。装飾は体の輪郭の
  内側か上に重ねる。輪郭の外へはみ出す楕円などは汚れに見える。
- 新規 SVG は既存武器・キャラと**同一キャンバス/回転中心**で作ると
  ゲーム内の位置合わせが不要になる（実績: 抜刀剣は大剣と同一にした）。
- SVG の軽量化（minify、埋め込み PNG の再圧縮）は MOD 側の既存ツールの流儀に従う。

## 種類別の必須セット

| 対象 | 必須コスチューム | 備考 |
|---|---|---|
| キャラ | body / body+ / hand / banner | banner 無しだとツリー詳細が出ない。神話は body++ / hand++ を追加 |
| 武器 | held（素の名前）/ @アイコン / *ショップカード | * は連続ブロック内。`<名前` や `:名前` は無い武器もあり欠けは許容 |
| 弾 | `:弾名` | 無いと弾が無言で見えない |
| 設置物 | `:名前` | Draw_bullet が ":" + 名前で描く |
| ガード | `C<名前>` 系 | プログラム名と一致させる |
| バフ | `^<バフ名>` | 無いと表示で化ける |
| サウンド連動 | 同名サウンド | 武器の発射音は弾名と同名サウンド。無ければ無音 |

- ショップカード（*）の中身は武器の絵ではなくテキストカード:
  カテゴリ表記、英語名、説明文（複数行）が SVG 内テキスト。
  既存カード（同カテゴリ）をコピーし、テキストと配色だけ差し替える。
  英語名が長い場合はカード内で scale を縮小する（実績: 0.30）。
- バナー（キャラ詳細カード）の構造は `tact-aim-add-character` 参照
  （471×115、tspan 6個 = 英語名/二つ名/フレーバー×4）。

## プレビューと確認

- プレビューは **body+ / body++ / ポートレートの3面**で目視確認してから出す。
- スキンの描き下ろしは1体ずつ作者確認を取る。顔向きが合っていないものは
  「できた」と報告しない。
- 成果物とプレビューは永続する場所（workspace 配下）に置く（/tmp は消える）。
